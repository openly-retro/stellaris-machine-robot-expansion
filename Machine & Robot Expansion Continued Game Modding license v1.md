# Machine & Robot Expansion: Continued Game Modding License v1.0

This document sets the rules about what people can do with the contents of this mod, divided into freedoms and restrictions. Anyone may copy this license document and modify it for their own project, just change the name of it.

"Machine & Robot Expansion: Continued" is a mod for Stellaris. Stellaris is a game commercially produced by Paradox Interactive.

# Freedoms

## Free to play

This mod is made free to play to anyone who has a copy of Stellaris.

## Freedom to download and modify the mod for personal use

Plain and simple, anyone can download this mod to their computer(s) and modify it for their personal use with Stellaris.

## Freedom to share with others

You can share modified versions of this mod with friends (why would we even try to stop you..)

## Freedom to upload and publish unsupported versions of this mod earlier than Stellaris 3.9

This mod has three versions published: One for Stellaris 3.9 (the original by XVCV), Stellaris 3.14, and one for "the most recent version of Stellaris". Anyone is free to publish a version of this mod that is compatible with editions of Stellaris earlier than 3.9.

If you do so, name it along the lines of "Machine & Robot Expansion <version> unsupported" where <version> is something like 3.9, and make it clear that the mod is not an officially supported version of the active "Machine & Robot Expansion: Continued" mod, but it is allowed under this Game Modding license, which must also be included along with the modified copy of the mod.

If you do so, you are solely responsible for the code and the work. Do yourself a favor and *do not* attempt to use LLMs to backport this mod to versions before 3.9.. you will end up with a massive unworkable mess.

## Freedom to use artworks in this mod only in other mods for Stellaris

You must provide credit back to this mod and notify the active modders here, either through making a Github issue (preferred) or notifying the mod authors via the Stellaris Modding Discord.

## Freedom to contribute to this mod

You are welcome to help improve the mod and propose code changes to it through pull requests on Github.

### LLM contribution policy

Any pull requests that were made with LLM assistance will be declined. Refunds cannot be given for any tokens spent on pull requests for this mod.

## Freedom to continue this mod on timed disappearance of authors, with no successors declared

This mod can be considered abandoned, if, after 6-8 months of reasonable efforts to contact previously active contributors to this mod, no mod authors respond. Reasonable efforts include leaving messages on the Steam Workshop page for this mod, and through issues on Github.

Only after such time has passed and the mod contributors (Openly Retro, Legit-Rikk) haven't responded, that the mod can be considered abandoned, and permission is given to re-upload modified versions of this mod and continue working on it.

Any continuations must be made freely available, along with the mod code in a publicly visible code forge (doesn't have to be Github), and this document.

Any continuations must be made without the use of LLM tools.

It should also be noted that the existence of this freedom is not a secret signal that the mod authors plan to abandon it.
